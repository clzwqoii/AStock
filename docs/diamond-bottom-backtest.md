# 「钻石底」回测报告 — 视频主张被数据否定

> 回测脚本：`tool/diamond_bottom.dart`（自检 + 全市场扫描，19 秒跑完）
> 样本：4776 只 · 可评估日 2,409,790 个（护栏后）· 数据区间 20231009~20260930
> 口径：除权 + 停牌护栏与 `backtestRule` 一致，信号与基准取同一批可评估日

---

## 结论（一句话）

**视频的核心主张「目标位 = 颈线位 × 2 够用」在全市场回测里不成立。**
持有 40 日时只有 **3.0%** 的信号触及 2 倍目标，**45.8%** 打到止损位。
这个形态有统计意义上的正期望，但期望**不是从「2 倍目标」来的**。

---

## 核心数据（持有 40 日 · 箱体 40 根 · 目标 2.0 倍 = 视频主张）

| 指标 | 数值 | 解读 |
|---|---|---|
| 信号数 | 16,735 | 样本足够，不是小数字噪声 |
| **触及目标%** | **3.0%** | 视频说「2 倍够够的」——实际 32 笔里只有 1 笔 |
| 止损% | 45.8% | 不到一半的信号在触及目标前先破颈线位 |
| 超时% | 51.2% | 过半是「没走出来也没破位」的震荡 |
| 均收益% | +6.39 | 看起来不错 —— 但见下一行 |
| **中位收益%** | **−2.69** | **中位数是亏的** |
| 同批基准均收益% | +4.32 | 基准不是零，是 +4.32 |
| **均收益差** | **+2.06pp** | 真正的超额只有 2 个点 |
| 剔 top1% 后均收益% | +5.46 | 去掉最好的 1% 信号后还剩 +5.46，**没塌** |

---

## 三个必须说清的发现

### 1. 中位数是负的，均值是正的 —— 分布极度右偏

持有 40 日时：中位 **−2.69%**，均值 **+6.39%**。
意味着**典型的一笔是亏的，赚的钱全靠少数暴涨股**。

但右偏敏感性检查（剔掉最好的 1%）后均值仍有 +5.46%，**没有塌成负数**。
→ 这个形态**不是纯噪声**，但也**不是靠运气**。它是一类高方差、正偏的信号。

**这解释了为什么视频看着准**：盘感训练展示的必然是涨得好的那些，
观众看到的是右尾，不是中位数。视频里那句「看看这个最低的颈线位的 2 倍，
这已经是 2 倍够够的呀」——是**事后对着已经涨出来的图量目标**。

### 2. 目标倍数几乎不影响期望 —— 1.5 倍比 2 倍更实用

| 目标倍数 | 触及率(40日) | 均收益(40日) |
|---|---|---|
| 1.5× | 13.7% | +6.40 |
| **2.0×**（视频主张） | **3.0%** | **+6.39** |
| 2.5× | 1.0% | +6.38 |
| 3.0× | 0.4% | +6.31 |

**均收益几乎不变（6.31~6.40），但触及率从 13.7% 崩到 0.4%。**
→ 目标位定多高根本不重要，**因为极少有信号真能到**。
视频强调「2 倍」这个数字，在数据上找不到对应的收益结构。

如果非要给目标位，**1.5 倍比 2 倍可达性高 4.5 倍，收益还不差**。

### 3. 持有期越长，超额越小 —— 120 日时已经跑输基准

| 持有期 | 基准均收益 | 信号均收益 | 超额 |
|---|---|---|---|
| 20 日 | +2.03% | +6.03% | **+1.71pp** |
| 40 日 | +4.32% | +6.39% | +2.06pp |
| 60 日 | +6.02% | +6.37% | +0.35pp |
| **120 日** | **+10.93%** | **+8.11%** | **−2.82pp** |

基准在 120 日 +10.93%（A 股中小盘长期漂移），形态只有 +8.11%。
**超额在 40 日后单调衰减并转负。**
→ 这个形态是**短中期信号**，拿它做长线持有会跑输。
视频全程没提持有期，这是最要紧的缺口。

## 方法学：视频规则 → 可计算判定

| 视频原话 | 回测实现 | 说明 |
|---|---|---|
| 底部低点 | `ind.highestHigh` 前 N 日箱体 | 客观代理，视频是手绘 |
| 颈线位 | 箱体上沿 | 同上 |
| 「直接干进去 / 突破颈线位」 | `close > neckline` | 放量门槛：量比 ≥ 1.2 |
| 「回踩不破颈线位」 | 回踩期最低价 ≥ 颈线×(1−3%) 且须真触及 | 视频没给容差，此处 3% |
| 「阳线再启动」 | `close > open` | |
| 「目标位 = 颈线位 × 2」 | 逐笔三路径模拟 | 唯一必须自己实现的部分 |
| 止损（视频没给） | 跌破颈线位×(1−3%) | **我加的，不是视频的** |
| 离场（MACD/量能背离） | **未实现** | 见「这份回测没测什么」 |

---

## 这份回测没测什么（不夸大结论）

1. **视频的离场条件完全没测** —— MACD 背离、量能柱 背离、「上攻乏力」都没实现。
   视频的完整主张是「进场 → 持有 → 背离时离场」，本次只测了前半段。
2. **止损位是我加的**，视频明确没给。本报告的「止损率」是**在假设止损位下的**结果，
   换止损位数字会变。
3. **同根 K 线同时触及目标与止损时判「目标」** —— 日线无法分辨先后，可能高估。
4. 未计交易成本、滑点、涨跌停无法成交。
5. 颈线位用了 `ind.highestHigh` 作客观代理，与视频手绘线不会完全一致。
6. 按 AGENTS.md 规则 4，**逐笔统计不等于独立样本** —— 实测独立交易日远少于
   16,735，真实置信区间比表面数字宽得多。这里只报点估计，没做按天聚类 bootstrap。

## 和「双底/箱体突破」的关系

回测用的判定链（箱体上沿突破 → 回踩不破 → 阳线再启动）与项目里已有的
`pivot_breakout_pullback`（中枢突破回抽不破）**同构**。

也就是说：**「钻石底」在数据上就是箱体突破 + 回踩确认**，
真正起作用的只有「颈线位突破 + 回踩不破」这两个可验证条件，
「钻石底」这个名字不携带任何额外信息。

**建议**：不要为它新增 `builtInRules` 条目。真要用，用
`pivot_breakout_pullback` 就行 —— 它有现成的 `explain` 诊断、
已登记在 `builtInRules`、回测口径与其它规则同源。
新增一个同构规则只会造成「两条规则统计打架，结论从哪条取」的问题。
