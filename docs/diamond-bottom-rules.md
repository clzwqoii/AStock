# 「钻石底」规则拆解 — 来自《千盘试炼400》第 1 集

> 来源：抖音视频《千盘试炼400》带表弟做炒股训练：钻石底（144秒，1080×1440）
> 拆解方式：**本地抽帧 36 张 + 本地语音转录 109 段**（faster-whisper small，音频不出本机），
> 术语用画面标注校正（small 模型同音字多，如「紧线位」= 颈线位、「回彩」= 回踩、「备词/备疑」= 背离）。
> 训练前提（字幕原文）：**裸K 盘感训练 · 未知票 · 未知时间 · 未知消息面**

---

## 一、钻石底的结构定义

视频里反复画在K 线图上的红色标记，从标注可以读出完整结构：

| 要素 | 画面/台词依据 | 含义 |
|---|---|---|
| **左侧底** | 各帧左下方红圈标记（如 2月17日、3月9日、3月27日、5月9日、5月31日 附近的那个低点） | 形态的起点，圈出来的那一根 |
| **颈线位** | 30 秒帧红字「下方：颈线位」，一条贯穿全图的红色水平线 | 多空分界，突破它才算形态成立 |
| **上方压力区** | 台词：「颈线位的支撑，上面这里还有压力区」 | 颈线位上方的前高套牢盘，构成第一阻力 |
| **突破 → 回踩** | 台词：「突破过后上走，回踩颈线位再突破」 | 二次确认，**回踩不破颈线位**是关键 |
| **目标位 = 颈线位高度 × 2** | 台词：「最低的颈线位的 2 倍，这已经是 2 倍，够够的呀」 | 测量目标，不是预测 |
| **第三重验证：MACD + 量能柱** | 126 秒帧红字清单 | 见下方「三层共振」 |

## 二、交易流程（视频原话顺序）

1. **底部最高位这么高，然后往上面去** —— 先量底部结构的高度，定第一目标
2. **直接干进去 / 这要在颈线位突破** —— 突破颈线位进场
3. **突破过后上走回踩颈线位，再突破，继续加仓** —— 回踩确认后是加仓点，不是退出点
4. **打到上方压力区，继续回踩；结果回踩不跌破，阳线长出来的地方就是洗盘** —— 关键判断：**回踩不破 = 洗盘，不是反转**
5. **阻力就是把你洗出去，然后再拉伸** —— 手法说明，全文引用这句
6. **目标位看 4** / **2 倍已经够够的** —— 到目标位附近开始观察上攻乏力

## 三、离场/警示信号（126 秒帧的红字清单，原文照抄）

```
* 上攻乏力
* MACD 背离
* 量能柱 背离
```

台词补充：「**它有 3 成风险**」、「总级别上走回踩，这内部不是小背驰吗？如果跌破的话，那就要留意了」。

- **小背驰** —— 内部的次级别背驰，是最早的减仓信号
- **跌破颈线位** —— 台词：「这一个小背驰，其实通过形态结果来讲的话」，即形态被破坏

## 四、失败案例：假突破（22 秒帧）

红字原文「**突破失败**」。处理逻辑：
- 突破颈线位后立刻回落
- 22 秒帧显示假突破后价格回落到颈线位下方
- 训练时的判法是：先看回踩是否跌破，再决定是「洗盘」还是「假突破」

**注意**：视频里没有明确给出「假突破的量化止损幅度」，只说「回踩跌破就要留意」。这是规则的缺口。

## 五、这套规则的可执行清单（从视频提炼，标注哪些是明确的、哪些是缺口）

### 明确的
- [x] 形态 = 底部低点 + 颈线位（水平线）
- [x] 进场 = 突破颈线位
- [x] 加仓 = 回踩颈线位不破 + 阳线重新拉起
- [x] 第一目标 = 颈线位高度 × 2
- [x] 洗盘判定 = 打到上方压力区后回踩不破颈线位
- [x] 风险信号 = 上攻乏力 + MACD 背离 + 量能柱 背离（三者共振）
- [x] 减仓信号 = 出现小背驰

### 视频没给、需要自己定的（**不要照搬这套规则去实盘前必须补上**）
- [ ] 颈线位画法没有客观标准 —— 视频是手绘 subjective 位置，不同人画出来不一样
- [ ] 没有止损位 —— 只说「跌破要留意」，没说跌多少走
- [ ] 没有仓位管理 —— 「直接干进去」「继续加仓」都是满仓加码的表述
- [ ] 没有假突破的量化判据
- [ ] 没有回踩的时间/幅度限制 —— 洗盘和真跌破在结构上无法区分
- [ ] 没有说明适用周期 —— 视频全程用日K，但标题是「盘感」训练，可能跨周期不通用

## 六、这套形态的理论位置

「钻石底」不是 mainstream 教科书形态。它在结构上接近：
- **双底 / 头肩底（W+M）** —— 都有「两个低点 + 一条颈线」的结构
- **矩形整理突破** —— 「颈线位 + 上方压力区」本质是箱体的上下沿
- 与「平台突破 + 回踩确认」的量价逻辑一致

也就是说，**它更像是「双底/箱体突破」的一个命名包装**，而不是独立的新形态。这个判断对实盘很重要：真正起作用的不是「钻石底」这个名字，而是「颈线位突破 + 回踩不破」这两个可验证的条件。

## 七、和当前项目的关系

`stock` 项目里已有 `lib/core/market.dart` 的除权/停牌护栏，和这里形态判断的**数据口径问题**高度相关：

- 视频是**裸K 复权处理未知**。库里是不复权价（`AGENTS.md` 规则 0），除权日会留永久断层。
- 如果按这套规则去回测，「颈线位」在除权股上会被断层污染 —— 除权跳空会看起来像「跌破颈线位」，实际是价格口径变化。
- 视频的量能柱背离判断，也需要确认成交量单位（库里统一**手**，tushare daily 口径）。

**结论**：把「钻石底」写成 `builtInRules` 之前，必须先走 `lib/core/market.dart` 的 `isCorporateActionGap` 过滤，否则回测结果不可信 —— 这正是 AGENTS.md 规则 0 要求的。

## 附：本机怎么读视频/音频（可复用）

```bash
# 1. 抽帧（ffmpeg 用 venv 里的静态二进制，不需要 brew install）
FF=/Users/chenliang/.workbuddy/binaries/python/envs/default/lib/python3.13/site-packages/imageio_ffmpeg/binaries/ffmpeg-macos-aarch64-v7.1
$FF -ss 30 -i "视频.mp4" -frames:v 1 -vf "crop=1080:640:0:60,scale=720:-1" -y /tmp/frame.jpg

# 2. 抽音轨（16k 单声道 wav，faster-whisper 要求）
$FF -i "视频.mp4" -vn -ac 1 -ar 16000 -c:a pcm_s16le -y /tmp/audio.wav

# 3. 本地转录（不联网调用，音频不出本机）
/Users/chenliang/.workbuddy/binaries/python/envs/default/bin/python \
  /tmp/stockvid/transcribe.py /tmp/audio.wav small /tmp/transcript
# 输出 /tmp/transcript.txt（带时间戳）+ .srt（字幕）
```

脚本位置：`/tmp/stockvid/transcribe.py`（读 wav → float32 numpy 直传，绕开 faster-whisper 对 PyAV 19 的 `metadata_errors` 报错）
